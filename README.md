# DRYCURED

Digitalna enciklopedija suhomesnatih proizvoda.

---

## Što je DRYCURED

DRYCURED je sadržajni i web projekt temeljen na knjizi:

> Enciklopedija suhomesnatih proizvoda

Projekt obuhvaća:
- web stranicu (drycured.com)
- knjigu (LaTeX)
- buduću mobilnu aplikaciju
- strukturirane recepte i tehnološke procese

---

## Arhitektura

Projekt je podijeljen na dva dijela:

### 1. DRYCURED (ovaj repo)
- sadržaj
- web struktura
- dokumentacija
- migracija knjige → web

### 2. SWAB-V2 (odvojeni repo)
- AI sustav
- automatizacija
- deploy
- integracija
