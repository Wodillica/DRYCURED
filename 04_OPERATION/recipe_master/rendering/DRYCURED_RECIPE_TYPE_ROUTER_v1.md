# DRYCURED RECIPE TYPE ROUTER v1

Datum: 2026-06-30

## 1. Mljeveni trajni proizvodi u omotaču

Primjeri:
- kobasice
- salame
- kulen
- kulenova seka
- sudžuk

Koristi se DCV5/Istarska model.

## 2. Komadni proizvodi

Primjeri:
- pršut
- šunka
- panceta
- vrat
- plećka
- slanina
- lardo
- bresaola

Ne koristiti kobasičarski model bez prilagodbe.  
Ne prikazivati generički blok crijeva.  
Ne prikazivati generički blok tekućine i češnjaka ako ga recept stvarno ne koristi.

## 3. Proizvodi s toplinskom obradom

Primjeri:
- barene kobasice
- kuhane kobasice
- krvavice
- tlačenice
- jetrenjače
- pečenice

Mora imati temperaturu obrade, trajanje, hlađenje i sigurnosne kontrole.

## 4. Sušena riba i posebni proizvodi

Koristi se poseban model.  
Ne koristiti kobasičarski ni komadni mesni model bez prilagodbe.

## Opće pravilo

Prije uređivanja recepta prvo se određuje tehnološki tip.  
Tek nakon toga se puni odgovarajući model.
