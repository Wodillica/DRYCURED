# Evidence matrix — Batch 01 cijeli komadi

Ova mapa sadrži uredničku matricu dokaza za prvih 25 javnih recepata iz skupine `CIJELI_KOMAD`.

Izvještaj je nastao iz master pilota:

- `04_OPERATION/recipe_master/drycured_recipes_master_v1_pilot_cijeli_komadi_25.json`

Radni izvorni report:

- `server-reports/recipes/master_editorial_matrix_cijeli_komadi_25_20260609_160416/`

## Namjena

Ovo nije konačni receptni sadržaj.

Matrica služi samo za dokazivanje koji se tragovi nalaze u izvornom `full_markdown` tekstu:

- država / regija
- anatomski komad
- pac / salamura / marinada
- sol i začini
- utrljavanje / potapanje / premazivanje
- trajanje i temperatura
- okretanje / prešanje
- dimljenje
- sušenje
- zrenje
- gotovost
- greške i rješenja
- sigurnost
- posluživanje i čuvanje

## Pravilo

Podaci iz ove matrice smiju se pretvarati u master blokove samo ako su:

1. jasno potvrđeni u izvoru,
2. tehnološki logični za skupinu `CIJELI_KOMAD`,
3. bez zabranjenih blokova za ovu skupinu: mljevenje, granulacija, crijevo, nadjev, miješanje nadjeva i punjenje.

Ako matrica nema jasan dokaz, blok se označava kao `needs_editorial_completion`, `not_applicable` ili se dopunjava tek nakon dodatne provjere izvora.
