# Drycured Latest Posts Plugin

Custom WordPress plugin for the shortcode `[drycured_latest_posts]`.

## Shortcode

Default usage:

```text
[drycured_latest_posts]
```

With parameters:

```text
[drycured_latest_posts posts_per_page="3" category_name="clanci"]
```

## Intended install location

Copy the plugin folder into the WordPress site at:

```text
wp-content/plugins/drycured-latest-posts/
```

Then activate it in WordPress Admin > Plugins.
