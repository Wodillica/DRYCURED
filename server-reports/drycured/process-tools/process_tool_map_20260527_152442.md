## Pravila za buduće radove

1. Ne presretati globalno linkove alata.
2. Ne stvarati privremene stranice alata bez provjere stvarnog shortcodea i postojeće WP stranice.
3. Svaki alat najprije mapirati: URL, page ID, shortcode, meni, mjesto prikaza.
4. Svaku procesnu dopunu raditi kroz vlastiti MU-plugin ili budući centralni process hub.
5. Nakon svake veće dopune: HTTP check, marker check, image check, PHP lint, git commit.

## Tehnički dug

- U wp-content/mu-plugins postoji više .bak i .disabled datoteka.
- Neke stare .bak datoteke imaju PHP parse greške pri ručnom lintanju, ali nisu aktivni MU-pluginovi.
- Preporuka: kasnije ih premjestiti u arhivu izvan mu-plugins mape, tek nakon backup-a.
