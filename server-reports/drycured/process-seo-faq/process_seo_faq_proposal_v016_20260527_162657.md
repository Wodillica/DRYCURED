# Drycured.com — SEO + FAQ prijedlog za procesne stranice v0.1.6

## Status

Ovo je prijedlog.  
Nema izmjena na WordPress produkciji.

## Cilj

Svaka procesna stranica treba dobiti:

- jasan SEO title
- meta description
- FAQ blok za korisnike
- FAQPage schema markup u kasnijem tehničkom koraku
- bolju internu vezu prema alatima, člancima Enciklopedije znanja i receptima

## Opće pravilo za sve stranice

SEO ne smije biti pisanje za robote.  
Tekst mora biti koristan čovjeku koji radi proizvod kod kuće ili u maloj proizvodnji.

Svaki FAQ odgovor mora sadržavati praktično rješenje, ne samo opis problema.

## Tehnička preporuka za implementaciju

Prvi kodni korak ne smije mijenjati postojeći tekst stranica.

Predloženi pristup:

1. izraditi `drycured-process-seo-faq.php` kao isključeni MU-plugin
2. spremiti SEO/FAQ mapu u funkciji ili JSON strukturi
3. dodati admin-only pregled prijedloga
4. tek nakon pregleda omogućiti meta title / description i FAQ schema
5. uključivati jednu po jednu stranicu, ne svih 12 odjednom

## Rollback filozofija

Svaka implementacija mora imati:

- opciju za potpuno isključivanje
- backup
- HTTP check
- HTML check
- schema check
- Git commit

Prvi javni korak mora biti reverzibilan jednom opcijom.
