# CODEX TASK — WEB SCRAPING PREP v1

## Cilj

Pripremiti operativni kostur za budući web scraping recepata suhomesnatih proizvoda bez pokretanja punog crawla.

## Što napraviti

1. pregledati dokumente u mapi `scraping_recepata`
2. potvrditi da postoje:
   - README
   - seed lista domena
   - višejezične ključne riječi
   - scrape policy
   - parser strategija
   - dedupe pravila
   - web schema
3. predložiti koje domene treba testirati u prvom batchu
4. sastaviti prijedlog male testne liste domena
5. predložiti koje izvore odmah preskočiti ili staviti u review status

## Što ne raditi u ovom koraku
- ne pokretati puni crawl
- ne spremati sirove scrape podatke u repo
- ne širiti seed listu na stotine domena bez pregleda
- ne mijenjati kanonska pravila bez dokumentiranja

## Izlaz

Izraditi izvještaj pod nazivom:
`WEB_SCRAPING_PREP_REPORT_v1.md`

Izvještaj treba sadržavati:
- procjenu spremnosti dokumentacijskog paketa
- popis nedostajućih elemenata
- prijedlog testnih domena
- prijedlog tehničkog redoslijeda implementacije
- upozorenja i rizike
