# DRYCURED_HOME_CURRENT_VS_INTERACTION_DIFF_v1

Status: radni diff v1  
Projekt: drycured.com  
Temelj usporedbe: live Home snapshot 2026-03-31 vs interaction copy spec v1

---

## 1. Current state

Trenutni live Home je čist Astra + Elementor editorial flow sa sekcijama:

- klasični header / menu
- hero
- `Učimo zajedno` kartice
- `Najnoviji članci`
- knjiga / trust blok
- audience / value blokovi
- uniqueness blok
- završni CTA

To je dobar temelj, ali još nije dovoljno jasno razdvojen po istinitosnim i funkcionalnim slojevima.

---

## 2. Target state

Interaction copy Home zadržava prepoznatljiv tok, ali uvodi:

- smart header
- verified zonu
- vanjske izvore / aktualno
- video / media zonu
- community / discussion zonu
- jači tools + knowledge gateway
- truth-layer označavanje sadržaja

---

## 3. Diff po sekcijama

### Header / menu

Current:

- standardni Astra menu
- Home, Recipes, Blog, Shop, My account, Knjiga — Preview
- GTranslate slot

Target:

- smart header
- zadržava glavnu navigaciju
- dodaje brze ulaze: Znanje, Problemi, Kalkulator, Aktualno
- language switcher postaje dio header logike, ne samo widget slot

Status:

- nadograđuje se

### Hero

Current:

- jak enciklopedijski positioning
- jedan glavni CTA `ISTRAŽI →`

Target:

- zadržava se isti positioning
- CTA logika postaje više operativna
- sekundarni ulaz prema problemima ili kalkulatoru

Status:

- ostaje i nadograđuje se

### Učimo zajedno / tri kartice

Current:

- Enciklopedija znanja
- Recepture
- Atlas stilova Europe

Target:

- ostaje kao temeljni gateway
- dio logike seli se u `Drycured Verified`
- dio logike ide u `Drycured Tools + Knowledge`

Status:

- zadržava se, ali se funkcionalno reparticionira

### Najnoviji članci

Current:

- interni latest posts blok

Target:

- ostaje kao interni verified feed
- mora dobiti jasnu oznaku da je to drycured sadržaj

Status:

- ostaje i truth-labela se

### Knjiga / trust blok

- ostaje

- ostaje

## 4. Zaključak

Ovaj diff potvrđuje da interaction copy nije totalni redesign nego disciplinirana nadogradnja live Home logike. Najveća promjena nije nova estetika, nego nova urednička i navigacijska disciplina:

- što je naše
- što je vanjsko
- što je community
- što je alatni ulaz
