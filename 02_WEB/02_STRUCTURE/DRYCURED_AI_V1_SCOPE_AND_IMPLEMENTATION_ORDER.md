# DRYCURED_AI_V1_SCOPE_AND_IMPLEMENTATION_ORDER

Status: scope and order v1  
Projekt: drycured.com  
Jezik rada: hrvatski

---

## 1. Svrha dokumenta

Ovaj dokument zaključava minimalni v1 scope i redoslijed rada za prvi DRYCURED AI knowledge sloj.

---

## 2. V1 scope

V1 mora prioritetno pokrivati:
- najčešće probleme
- najvažnija teorijska pitanja
- mikroklimu
- faze procesa
- sušenje
- dimljenje
- osnovne warning logike
- najvrjednije tablice i infografike

V1 ne pokušava odmah pokriti svu enciklopediju jednako duboko.

---

## 3. Predloženi sadržajni prioritet

### Prioritet 1
- poglavlja o tehnološkim procesima
- mikroklima i klimatski uvjeti
- warning i problem logike
- tablice s parametrima i matricama

### Prioritet 2
- fermentacija i mikrobiologija
- sigurnost i higijena
- sirovine i pomoćni sastojci

### Prioritet 3
- kulturni/regionalni sloj
- tržišni i širi kontekst
- backmatter reference slojevi

---

## 4. Zaključani redoslijed rada

1. LaTeX structure audit  
2. knowledge object schema  
3. extraction pipeline design  
4. retrieval plan  
5. response model  
6. anti-hallucination rules  
7. v1 scope  
8. tek kasnije prototype / UI / web integration

---

## 5. Što se ne radi u ovom koraku

- finalni UI
- live deploy
- dizajn chata
- masovni import bez schema discipline
- slobodni chatbot bez source discipline

---

## 6. Što mora postojati prije prototype faze

- jasan source manifest knjige
- knowledge object schema
- extraction pravila za tablice i infografike
- retrieval strategija po modu rada
- dokazivi response model
- anti-hallucination guardrails

---

## 7. Zaključak

Prvi cilj nije “napraviti chatbot”, nego zaključati knowledge architecture tako da kasniji prototype i web integracija ne budu građeni na slabom temelju.
