# Drycured ops zapis — AIOSEO meta podaci za digitalne alate

Datum: 2026-06-29
Područje: drycured.com / SEO / alati
Komponenta: All in One SEO, tablica `wp_aioseo_posts`

## Razlog izmjene

Postojeće stranice digitalnih alata nisu sve imale ručno postavljen SEO naslov i meta opis.

## Izvršeno

Popunjeni su AIOSEO title i description za:

- `/kalkulator/`
- `/dnevnik-serije/`
- `/kalkulator-soli/`

Stranica `/kalkulator-susenja/` već je imala SEO podatke i nije mijenjana.

Glavna stranica `/alati/` već je imala SEO podatke i nije mijenjana.

Testna stranica `/kalkulator-test/` označena je kao noindex.

## Konačna provjera

Javni HTML prikazuje title, meta description, canonical, OG podatke i schema.org WebPage za:

- `/kalkulator/`
- `/dnevnik-serije/`
- `/kalkulator-soli/`

Za `/kalkulator-test/` javni HTML prikazuje:

- `<meta name="robots" content="noindex, max-image-preview:large" />`

## Napomena

Ovo je SEO i indeksacijski zahvat. Funkcionalnost alata nije mijenjana.
